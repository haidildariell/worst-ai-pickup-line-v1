Entry for the [make.fun bounty "The Worst Line an AI Could Say"](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f): a single pickup line, the worst one an AI could plausibly deliver — flat, over-helpful, faintly ominous.

`main.py` writes the line to `/output/entry.txt` (139 characters, UTF-8).
It validates the entry against the competition gate (1–140 characters,
not only whitespace) before writing it.

## Run

```sh
python3 main.py
```

Set `ENTRY_OUTPUT` to override the output path for local testing.
